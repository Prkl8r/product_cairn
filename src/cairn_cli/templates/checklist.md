# Checklist

Project-wide goals and commitments that span or sit above individual Threads
(e.g. "ship the new email feature by Monday"). Check items off yourself —
`whats-next` reads this file but never edits it. For a to-do tied to one
specific Thread's progress, use that Thread's own `## Open items` section
instead.

## Open

- [ ] Example: ship <feature> by <date> — may reference THRD-NNN
